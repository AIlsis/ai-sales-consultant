# Grok Bot 24h 自动工作流（Routines）

用 Grok Bot 的 Cloud Agent + Routines 跑这个顾问。重文案 / 复杂挽回话术让 Grok 路由到 Claude Opus，配图走 Midjourney，节日音频走 Suno。

## 三个固定 Routine

| 时间 | 动作 | 产出 |
|---|---|---|
| 每日 9:00 | 读昨日私信 / 企微记录（授权或手动粘贴）| 「客户分层 + 今日跟单清单」 |
| 每日 12:00 | 结合门店当日主推项目 | 朋友圈 / 小红书文案 2 条 |
| 每日 21:00 | 汇总当日互动 | 转化日报（跟了谁 / 流失谁 / 明天重点）|

## 客户分层逻辑

- **A 意向强**：主动问价格、问时间、要地址 → 当天促单
- **B 观望**：点赞 / 问细节但不定 → 3 天内养熟（案例 + 限时）
- **C 仅咨询**：问完没回 → 7 天轻触一次，不骚扰

## 话术库维护

每月把高转化话术沉淀进 Agent 长期记忆，低转化的删掉。分场景模板见 `../prompts/`。

## Cloud Agent 配置要点

1. 把 `niche/beauty/profile.md` 作为「长期记忆」喂给 Agent，出话术才贴店；
2. 提示词用 `../agent/system_prompt.md`；
3. 设上述三个 Routines，让它 24h 在云端跑，老板关手机也在跟单。
